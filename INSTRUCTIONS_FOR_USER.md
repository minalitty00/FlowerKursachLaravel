## ✅ Задача 6: Сохранение фотографий товаров в репозитории
### Что сделано:
1. **Создана символическая ссылка** `public/storage` → `storage/app/public`
2. **Изменены настройки .gitignore**:
   - `storage/app/public/.gitignore` теперь не игнорирует папку `products/`
   - `.gitignore` в корне исключает `public/storage`, но включает `public/storage/products/`
3. **Создана структура папок**:
   - `storage/app/public/products/` - для хранения фотографий
   - `.gitignore` в папке `products` игнорирует только временные файлы
4. **Добавлены инструкции**:
   - `PHOTOS_GUIDE.md` - подробное руководство
   - `README.md` в папке `products` - краткие инструкции

### Как это работает:
- Фотографии товаров загружаются через админ-панель в `storage/app/public/products/`
- Через символическую ссылку доступны по пути `http://localhost:8000/storage/products/название_файла.jpg`
- **НОВЫЕ ФОТОГРАФИИ НЕ ДОБАВЛЯЮТСЯ В GIT АВТОМАТИЧЕСКИ**
- После загрузки фотографии нужно добавить в Git вручную:
  ```bash
  git add storage/app/public/products/название_фотографии.jpg
  ```
