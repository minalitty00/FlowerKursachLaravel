# Папка для фотографий товаров

В эту папку автоматически сохраняются фотографии товаров, загруженные через админ-панель.

## Как добавить фотографию в Git

После загрузки фотографии через админ-панель, выполните:

```bash
# Добавить конкретную фотографию
git add название_фотографии.jpg

# Или добавить все новые фотографии
git add .
```

## Структура
- Фотографии сохраняются с уникальными именами
- Поддерживаются форматы: JPG, PNG, GIF, WebP, SVG
- Временные файлы игнорируются (.tmp, .temp, .cache)

## Важно!
Новые фотографии НЕ добавляются в Git автоматически. Их нужно добавлять вручную после каждой загрузки.
