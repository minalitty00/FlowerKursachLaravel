## Запуск приложения

### 1. Запустить сервер Laravel
```bash
php artisan serve
```
Сервер запустится на http://localhost:8000

### 2. Запустить Vite для фронтенда (в отдельном терминале)
```bash
npm run dev
```

## Запуск тестов
```bash

# Только unit-тесты

# Только feature-тесты
php artisan test --testsuite=Feature
```

## Структура проекта
- `/app/Http/Controllers` - Контроллеры (API и Web)
- `/app/Models` - Модели Eloquent
- `/app/Services` - Бизнес-логика
- `/resources/views` - Blade шаблоны
- `/tests` - Unit и Feature тесты
- `/database/migrations` - Миграции БД
- `/database/seeders` - Сидеры для тестовых данных
