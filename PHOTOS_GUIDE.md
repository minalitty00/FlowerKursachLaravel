# Руководство по работе с фотографиями товаров

## Текущая настройка

1. **Символическая ссылка**: Создана ссылка `public/storage` → `storage/app/public`
2. **Хранение фотографий**: Фотографии товаров хранятся в `storage/app/public/products/`
3. **Git отслеживание**: Git отслеживает только папку `products/` внутри `storage/app/public/`

## Как добавлять новые фотографии товаров

### Через админ-панель
1. Зайдите в админ-панель: `http://localhost:8000/admin`
2. Перейдите в раздел "Товары"
3. Создайте новый товар или отредактируйте существующий
4. Загрузите фотографию через форму
5. Фотография автоматически сохранится в `storage/app/public/products/`

### Добавление фотографий в Git (ВРУЧНУЮ)
После загрузки фотографии через админ-панель, её нужно добавить в Git:

```bash
# Добавить конкретную фотографию
git add storage/app/public/products/название_фотографии.jpg

# Или добавить все новые фотографии
git add storage/app/public/products/
```

### Проверка статуса фотографий
```bash
# Проверить, какие фотографии не добавлены в Git
git status storage/app/public/products/

# Проверить, какие фотографии уже отслеживаются Git
git ls-files storage/app/public/products/
```

## Важные моменты

1. **Новые фотографии НЕ добавляются автоматически в Git** - их нужно добавлять вручную после загрузки
2. **Типы файлов**: Поддерживаются `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.svg`
3. **Временные файлы**: Игнорируются файлы `.tmp`, `.temp`, `.cache`, `Thumbs.db`, `.DS_Store`
4. **При переносе на другой компьютер**: После клонирования репозитория, фотографии товаров будут доступны сразу

## Устранение проблем

### Фотографии не отображаются на сайте
1. Проверьте, создана ли символическая ссылка:
   ```bash
   php artisan storage:link
   ```

2. Проверьте права доступа к папке:
   ```bash
   chmod -R 755 storage/app/public/products/
   ```

### Git игнорирует фотографии
1. Проверьте настройки `.gitignore`:
   - `storage/app/public/.gitignore` должен содержать `!products/` и `!products/*`
   - `.gitignore` в корне должен содержать `!/public/storage/products/`

2. Принудительно добавьте фотографии:
   ```bash
   git add -f storage/app/public/products/название_фотографии.jpg
   ```

## Структура папок
```
storage/app/public/
├── .gitignore          # Игнорирует всё, кроме products/
└── products/
    ├── .gitignore      # Игнорирует временные файлы, но не изображения
    ├── товар1.jpg      # Отслеживается Git
    ├── товар2.png      # Отслеживается Git
    └── ...
```

public/storage/ → символическая ссылка на storage/app/public/
